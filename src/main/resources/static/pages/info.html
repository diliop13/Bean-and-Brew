    💻 Developer's Note & Project Architecture

    Bean & Brew is a complete Full-Stack e-commerce web application, developed to demonstrate modern software engineering practices, relational database management, and RESTful API architecture.

    Tech Stack:

    • Backend: Java 21, Spring Boot (Spring Web, Spring Data JPA)
    • Database: PostgreSQL with Hibernate (ORM)
    • Frontend: HTML5, CSS3, Vanilla JavaScript (DOM manipulation & Fetch API for asynchronous communication)
    • Version Control: Git & GitHub
